# MCM AI - Demo ChatGPT cho website HTML

## Cấu trúc

- index.html
- api/chat.js

## Chạy trên Vercel

1. Đưa 2 file này lên GitHub.
2. Import repository vào Vercel.
3. Vào Project → Settings → Environment Variables.
4. Tạo biến:

OPENAI_API_KEY = API_KEY_CUA_BAN

Không đặt API key trong index.html.

5. Redeploy.

Sau khi deploy, mở website và thử:
"Tầm 15 triệu build cho tôi PC chơi Valorant"

Hoặc chọn linh kiện ở cột bên trái rồi bấm "Đánh giá cấu hình".

## Lưu ý

Đây là mẫu nền. Danh sách CPU/Main/VGA/RAM/SSD/PSU đang được viết trực tiếp trong HTML.
Bước tiếp theo có thể thay phần này bằng dữ liệu Excel/JSON của cửa hàng.
